📘 What is mdnet?

mdnet is a friendly, command-line tool that creates beautiful, AI-friendly documentation for your .NET libraries. It reads your code (from source files or NuGet packages) and automatically generates two things:

  • Markdown files – lightweight, readable text files perfect for developers, version control, and AI tools.
  • Static HTML pages – polished, web-based documentation that anyone can open in a browser (built with Markdoc).

The docs are "signature-first," meaning they focus on accurate function signatures and API references – exactly what AI coding assistants (like Claude Code) need to understand your code quickly and correctly.

Step 4: Run mdnet

Type this command and press Enter:

.\mdnet --help

You'll see a list of available commands. That's it – you're ready to generate docs!

To generate documentation for a NuGet package, use:

.\mdnet generate --package PackageName

Or for your local source code:

.\mdnet generate --source "C:\path\to\your\project"
